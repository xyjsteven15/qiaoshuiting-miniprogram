## 2. 楼层详细说明

### L0 · 顶部品牌栏

| 元素 | 说明 |
|------|------|
| 品牌字标 | 「桥水汀」，宋/楷类衬线，字重克制 |
| 装饰 | 字标下方一条极细琥珀金线（1px 视觉量级） |
| 右侧 | 氛围音开关（默认关，古琴/雨声）；图标极简，不抢品牌 |

**职责**：品牌即首要信号；去掉后首屏仍应能识别为桥水汀，而非通用餐饮模板。

---

### L1 · 沉浸 Hero（首屏主视觉）

| 元素 | 说明 |
|------|------|
| 媒体 | 全宽、edge-to-edge 短视频静音循环，或高质量静帧；马头墙 / 厅堂光影 / 宣纸肌理 |
| 品牌名 | Hero 内再次强化「桥水汀」（建议顶栏常驻、Hero 内以一句品牌语为主） |
| 品牌语 | 一句，如：「新派徽菜 · 大隐于市的一席私宴」 |
| CTA | **单一**「即时订座」→ 跳转订座 Tab / 订座流程页（全宽按钮） |

**禁止**：浮动徽章、促销贴纸、地址块、本周活动、统计数字条、圆角媒体卡片、侧栏插图。

**动效**：视频缓慢推镜或宣纸纹理轻微呼吸（透明度/位移极小）；进入页 300–450ms 淡入。

---

### L2 · 今日空位速览

| 元素 | 说明 |
|------|------|
| 标题 | 「今日空位」或「厅堂雅座」；衬线小标题 |
| 时段切换 | 午市 / 晚市（Segmented，琥珀金选中细线，非大圆角胶囊堆） |
| 四厅状态 | **一行**排列：桥遇厅 · 羡鱼轩 · 垂虹居 · 徽来堂；徽来堂旁小字「KTV」 |
| 状态表达 | 可订＝黛青字；已订＝浅灰；锁定中＝琥珀金描边（本人）；关停＝浅灰+「暂不开放」 |
| 点击 | 可订厅 → 进入该厅详情（带入今日 + 当前时段）；整行「查看全部档期」链到订座 Tab |

**布局原则**：信息条带，**不是**四张独立阴影卡片。去除边框/阴影后仍可理解。

---

### L3 · 时令一席（季节限定展示）

| 元素 | 说明 |
|------|------|
| 主视觉 | 一道季限定菜或一席摆台的全宽/近全宽影像（非多图拼贴） |
| 节气角标 | 如「谷雨 · 时令」，排版克制，贴边即可，不做漂浮贴纸感 |
| 主厨推荐 | 印章式小标签「主厨推荐」 |
| 酒水一句 | 衬线小字，如「宜配：黄山毛峰佐味」 |
| CTA | 「即刻订座」→ 订座 Tab |

**一节一目的**：唤起时令食欲并导入订座（一期不做线上点餐，仅作展示引导）。

---

### L4 · 厅堂探景横滑

| 元素 | 说明 |
|------|------|
| 标题 | 「厅堂探景」 |
| 内容 | 横向滑动四厅缩略：桥遇厅、羡鱼轩、垂虹居、徽来堂 |
| 徽来堂 | 缩略上可有极简「KTV」字样 |
| 点击 | 进入溯源 · 包厢探景对应厅（视频/VR） |

**注意**：横滑是浏览手段，缩略图本身不做促销卡片化（无价格、无「立即预订」重叠按钮；预订在 L2/订座完成）。

---

### L5 · 徽商一则

| 元素 | 说明 |
|------|------|
| 形式 | 短叙事（3–5 行）+ 「阅读溯源」文字链 |
| 内容示例 | 徽商「贾而好儒、礼遇宾客」与桥水汀今日一席之间的一句桥接 |
| 点击 | 进入溯源 Tab · 徽商叙事轴对应章节 |

**一节一目的**：文化信任，不堆砌多篇列表。

---

### L6 · 履约保障条

| 元素 | 说明 |
|------|------|
| 三项信息 | 定金锁位 · 私密雅叙 · 徽味融合 |
| 样式 | 底栏式文字行；低对比，收束页面 |

## 3. 组件与跳转矩阵

| 楼层 | 用户动作 | 目标 |
|------|----------|------|

| L2 时段切换 | 切换 | 刷新四厅状态（当日 + daypart） |

| L5 阅读溯源 | 点击 | 溯源 · 徽商叙事 |
| L0 氛围音 | 点击 | 切换古琴/雨声 BGM |

## 4. 交互与情感细节

| 项目 | 规范 |
|------|------|
| 页面进入 | 整体 opacity + 轻微上移 8–12px，300–450ms ease-out |
| 楼层出现 | 滚动至可视区时依次淡入，间隔短、不花哨 |
| Hero 媒体 | 静音；若系统省电/弱网则降级为静帧 |
| 空位刷新 | 进入首页、切换午晚市时拉取；可订→已订需近实时（轮询或订阅，实现期定） |
| BGM | 不在首页自动播放；仅用户在顶栏主动开启 |

---

## 5. 响应式与适配

| 场景 | 要求 |
|------|------|
| 常规手机 | Hero 占首屏可视高度约 70–100%（含顶栏），保证首屏「一构图」 |
| 全面屏安全区 | 顶栏避开状态栏/胶囊；底 Tab 避开 Home Indicator |
| 横滑 L4 | 露出下一厅约 16–24px，提示可滑 |
| 弱网 | L1/L3 图片占位用宣纸底色，避免白屏闪烁 |

## 7. 设计验收清单

- [ ] 去掉顶栏导航后，首屏仍能通过字标/气质识别为「桥水汀」

- [ ] 首屏为单一「即时订座」CTA（无邀请函等其他入口）
- [ ] 底部导航为四栏：汀遇 / 溯源 / 订座 / 我的
